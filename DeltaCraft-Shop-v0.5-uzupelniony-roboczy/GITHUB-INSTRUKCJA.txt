DEL TACRAFT SHOP - INSTRUKCJA GITHUB

1. Utworz PUSTE repozytorium GitHub.
2. Rozpakuj ZIP.
3. Wgraj ZAWARTOSC folderu, a nie sam folder.
4. W katalogu glownym musza byc: .github, src, build.gradle, gradle.properties, settings.gradle.
5. Sprawdz, czy GitHub pokazuje .github/workflows/build.yml.
6. GitHub Actions > Build DeltaCraft Shop > Run workflow.
7. Jesli build sie nie powiedzie, skopiuj pierwszy blad z kroku Compile mod.

To jest wersja bazowa 0.1.0: ekonomia i MultiMine, bez GUI sklepu.
Kompilacja na GitHub Actions nie zostala jeszcze potwierdzona.
